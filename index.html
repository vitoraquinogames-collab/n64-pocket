🎮 Xbox Edge — controle e tela cheia

Conecte um controle Xbox e pressione um botão. O painel mostra se o Edge reconhece o controle. O EmulatorJS faz seu próprio mapeamento; confira o menu de controles do emulador se os botões não corresponderem ao N64.

Aguardando controle Xbox...
Sugestão de mapeamento nas configurações do EmulatorJS: analógico esquerdo → analógico N64; A Xbox → A N64; X Xbox → B N64; gatilho esquerdo → Z; LB/RB → L/R; direcional ou analógico direito → botões C; Menu (≡) → Start. É uma sugestão, não uma configuração automática.
Algumas versões do Edge no Xbox não permitem Fullscreen API ou restringem seleção de arquivos locais. Se o botão de tela cheia falhar, use o modo de tela cheia do próprio Edge. A ROM não é incluída.
